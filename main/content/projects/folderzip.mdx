# FolderZip

An instant in-browser developer utility that converts ASCII folder tree representations into ready-to-use downloadable `.zip` archives.

## Why FolderZip?

Developers, teachers, and technical writers frequently share directory tree diagrams in documentation, GitHub READMEs, and tutorials:

```text
my-project/
├── src/
│   ├── index.ts
│   └── utils.ts
└── package.json
```

Manually recreating this folder hierarchy and creating empty files is tedious. FolderZip allows you to simply paste the ASCII tree or JSON representation, and click **Download ZIP**.

---

## Key Features

- **100% Client-Side**: All parsing and ZIP generation runs in the browser using JSZip; no files or directory trees are sent to any server.
- **Tree Syntax Support**: Intelligently handles standard Unicode and ASCII box-drawing characters (`├──`, `└──`, `│`, `|--`).
- **File & Directory Distinction**: Automatically detects file extensions vs nested directory levels.
- **Instant Archive Generation**: Packages folder hierarchies into compressed `.zip` downloads in milliseconds.
